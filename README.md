## ✦ The Philosophy

### Great interfaces are not accidents.

Exceptional digital experiences emerge from hundreds of thoughtful decisions.

The right easing curve.  
The perfect transition duration.  
The subtle response to a user's gesture.  
The careful balance between movement and stillness.

**Every detail contributes to the experience.**

This collection helps designers, developers, and AI coding agents make better interface decisions.

<br/>

### ◈ Design Principles

| Principle | Philosophy |
|:---:|:---|
| ✦ **Intentional Motion** | Every animation should communicate something meaningful. |
| ◈ **Visual Precision** | Typography, spacing, and hierarchy deserve attention. |
| ⚡ **Performance First** | Beautiful interactions should remain smooth and responsive. |
| ◎ **Human-Centered** | Design for how people actually interact with products. |
| ⬡ **Engineering Excellence** | Build interfaces that are elegant, reliable, and maintainable. |

# 🧩 Skill Directory

Explore the collection of specialized skills designed to improve the quality of AI-generated interfaces.

## ✦ 01. Animation Engineering

| Skill | Description |
|---|---|
| `animate` | Build polished animations with appropriate easing and duration. |
| `animate-expo` | Create native-feeling animations for React Native and Expo. |
| `animation-performance` | Identify and fix animation performance problems. |
| `animation-vocabulary` | Describe motion precisely using professional terminology. |
| `choreograph` | Coordinate multiple animations into cohesive sequences. |
| `gestures` | Build natural drag, swipe and gesture interactions. |
| `review-animations` | Review animation implementations for quality. |
| `improve-animations` | Audit and generate prioritized animation improvement plans. |
| `find-animation-opportunities` | Identify where animations add genuine value. |
| `remove-animations` | Remove unnecessary motion and distracting effects. |

## ✦ 02. Interface & Design Engineering

| Skill | Description |
|---|---|
| `emil-design-eng` | Apply design engineering principles and interface polish. |
| `apple-design` | Apply Apple's fluid interface and motion principles. |
| `pick-ui-library` | Select appropriate UI libraries for different requirements. |
| `prototype` | Generate multiple interface concepts for comparison. |
| `mobile-native` | Improve mobile web interactions and native-like behavior. |
| `break-ui` | Test interfaces against unusual and extreme content. |
| `ask-sonner` | Implement and customize Sonner toast notifications. |
| `write-swift` | Write modern Swift with strong engineering practices. |

### 01 — Intelligent Animation

- Appropriate easing curves.
- Natural motion and timing.
- Smooth transitions.
- Interruptible animations.

- Consistent spacing.
- Better typography.
- Visual hierarchy.
- Refined shadows and borders.
- Component-level polish.

### 03 — Performance Optimization

- Reduce unnecessary re-renders.
- Avoid expensive animation properties.
- Improve frame consistency.
- Optimize interaction responsiveness.
- Respect reduced-motion preferences.

- Native-feeling gestures.
- Smooth bottom sheets.
- Touch interaction feedback.
- Safe-area handling.
- Responsive layouts.

# 💻 Quick Start

### Step 1 — Install the Skills CLI

```bash
npm install -g skills
```

### Step 2 — Install the Repository

```bash
npx skills@latest add emilkowalski/skills
```

### Step 3 — Use a Specific Skill

```bash
npx skills@latest add emilkowalski/skills --skill animate
```

### Step 4 — Start Building

Try prompts such as:

```text
Build a beautiful animated landing page.

Use purposeful motion, smooth transitions,
refined typography and polished interactions.
```
